## 中文说明

**CheatMenu** 提供 F9 游戏内菜单：角色、资源、物品生成、徽章栏位、风神之息和中英文设置。**美术资源工具**包含导出 EXE 与查看 CMD，支持离线分类、搜索、筛选和分页；无需另装 Python 或 BepInEx。

### 安装顺序

1. 关闭游戏，先备份游戏目录中的 `userdata/saves`。
2. 首次安装菜单时，解压 **01 下载助手**，双击 `下载BepInEx前置.cmd`。它将真正的 BepInEx 原包下载到 **CMD 旁边的 Downloads 子文件夹**，不会直接安装。
3. 把新下载的 BepInEx 原包内部内容解压到游戏根目录；启动游戏完成初始化，进入主菜单后退出，再合并 **02** 包内的 `BepInEx` 文件夹。进入存档后按 **F9**。
4. 仅用美术工具时，将 **03** 解压到游戏目录，运行 `一键导出美术资源.exe`；以后用 `打开美术资源库.cmd` 打开已有结果。

## English

**CheatMenu** provides an F9 in-game menu for player adjustments, resources, item spawning, medallion slots, Vayu's Breath and Chinese/English settings. **Art Tool** combines an export EXE with an offline-gallery launcher, with categories, search, filters and pagination. No separate Python or BepInEx is needed for the art tool.

### Installation order

1. Close the game and back up `userdata/saves` inside its directory.
2. For first CheatMenu setup, extract **helper 01** and run `下载BepInEx前置.cmd`. It downloads the actual BepInEx archive into **Downloads beside the CMD**, without installing it.
3. Extract that newly downloaded BepInEx archive's contents into the game root. Start the game, finish initialization, reach the main menu and exit. Then merge the `BepInEx` folder from **02**. Enter a save and press **F9**.
4. For artwork only, extract **03** into the game directory and run `一键导出美术资源.exe` (export). Use `打开美术资源库.cmd` later to reopen existing results.
